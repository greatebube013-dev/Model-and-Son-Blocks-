# Model and Son Blocks Industry Nigerian Limited

A professional website showcasing the services and products of Model and Son Blocks Industry Nigerian Limited.

## Project Structure

- `index.html`: The main structure of the website.
- `style.css`: Styling for the website.
- `script.js`: Interactivity and smooth scrolling.

## Features

- Responsive design for mobile and desktop.
- Smooth scrolling navigation.
- Service and Product showcases.
- Contact form.

## Installation

Simply open `index.html` in any modern web browser to view the website or GitHub.
